Marble Marcher: Community Edition 调研

调研日期：2026-10-08；仅使用项目仓库和作者发布页。

- 社区版仓库：[WAUthethird/Marble-Marcher-Community-Edition](https://github.com/WAUthethird/Marble-Marcher-Community-Edition)。
- 原作者 README 明确将后续问题与贡献引导到这个社区版。[原作者推荐](https://github.com/HackerPoet/MarbleMarcher#no-further-development-planned)
- 玩法：控制弹珠通过程序渲染的分形地形，尽快到达旗帜；作者发布页介绍社区版包含 30 关。[玩法与关卡](https://michaelmoroz.itch.io/mmce)
- 许可证为 GNU GPL v2.0。[仓库 LICENSE](https://github.com/WAUthethird/Marble-Marcher-Community-Edition/blob/master/LICENSE)

两个值得展示的现有特性：

1. 自己制作分形赛道：支持自定义关卡，并带基础关卡／分形编辑器。[社区版功能列表](https://github.com/WAUthethird/Marble-Marcher-Community-Edition#changes)
2. 把分形游戏当作图形实验：可自定义并实时编辑着色器，截图分辨率最高 10K，且独立于游玩分辨率。[图形功能](https://github.com/WAUthethird/Marble-Marcher-Community-Edition#changes)、[画质设置](https://github.com/WAUthethird/Marble-Marcher-Community-Edition#graphics-settings)
